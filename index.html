Developer Documentation

Catatan Belajar Web Development

Daniel Docs adalah dokumentasi pribadi untuk menyimpan catatan, contoh kode, dan referensi pengembangan website.

Tujuan project

Project ini dibuat untuk mendokumentasikan proses belajar HTML, CSS, JavaScript, Git, dan GitHub Pages.

01

HTML Dasar

HTML digunakan untuk membangun struktur halaman website. HTML dapat digunakan untuk membuat judul, paragraf, gambar, link, daftar, dan berbagai elemen lainnya.

Struktur HTML

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Website Saya</title>
</head>
<body>
  <h1>Halo Dunia</h1>
</body>
</html>
  • h1 digunakan untuk judul utama.
  • p digunakan untuk paragraf.
  • a digunakan untuk link.
  • img digunakan untuk gambar.
  • section digunakan untuk bagian halaman.
02

CSS Dasar

CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran, jarak, layout, dan responsive design.

Contoh CSS

:root {
  --primary: #f97316;
  --text: #292524;
}

.card {
  padding: 24px;
  border-radius: 16px;
  background: white;
  color: var(--text);
}

Responsive design

@media (max-width: 700px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
03

JavaScript

JavaScript digunakan untuk menambahkan interaksi pada website, seperti menu, modal, pencarian, filter, dan validasi form.

Event tombol

const button = document.querySelector("#button");

button.addEventListener("click", () => {
  alert("Tombol berhasil diklik!");
});

Toggle class

const menu = document.querySelector(".menu");

menu.classList.toggle("active");
04

Git dan GitHub

Git digunakan untuk mencatat perubahan kode, sedangkan GitHub digunakan untuk menyimpan dan membagikan repository secara online.

Perintah Git dasar

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin URL_REPOSITORY
git push -u origin main
05

GitHub Pages

GitHub Pages digunakan untuk mempublikasikan website statis berbasis HTML, CSS, dan JavaScript.

  1. Buat repository baru.
  2. Tambahkan file index.html.
  3. Upload file CSS dan JavaScript.
  4. Buka menu Settings.
  5. Pilih Pages.
  6. Pilih branch main.
  7. Pilih folder root.
  8. Klik Save.
https://username.github.io/nama-repository/
